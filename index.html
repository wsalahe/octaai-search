Private search. No ads, no trackers, no cookies, no logs.

Web results from Marginalia Search (independent open-source index, results CC-BY-NC-SA 4.0) or SearXNG metasearch nodes. Knowledge results and instant answers from Wikipedia. Not enough? Widen this search with SearXNG metasearch.

Privacy, honestly: this page stores nothing and talks only to the search APIs needed to answer you. Your query is sent over HTTPS to the Marginalia Search API (and Wikipedia for instant answers); like any search backend, they can see the queries they answer. We never see, log, or sell them.
